# Quyết định kiến trúc (ADR)

Mỗi quyết định lớn là một file riêng, đặt tên `NNN-ten-quyet-dinh.md`:
- `NNN`: số thứ tự 3 chữ số, tăng dần, không dùng lại (`001`, `002`, ...).
- `ten-quyet-dinh`: chữ thường, không dấu, nối bằng gạch ngang (ví dụ `001-ghim-ag-ui-langgraph.md`).

Quyết định bị thay thế thì không xoá file cũ: ghi "Đã thay bằng NNN" ở mục Hệ quả.

## Mẫu

```markdown
# NNN: <Tên quyết định>
- Ngày:
- Bối cảnh:
- Quyết định:
- Lý do / phương án đã loại:
- Hệ quả:
```
